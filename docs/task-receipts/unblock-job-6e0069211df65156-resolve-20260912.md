## Finding and fix

The exclusive flock on `~/.mesh/job/hh-drive.start.lock` was held by PID 2198889,
`mesh-vantage-socks --port 1081`, which had inherited file descriptor 9 from
`mesh-hh-drive --start`. `start()` opens and locks fd 9, then launches the
vantage proxy before its browser daemon; neither background launch closed the
descriptor. The proxy therefore kept the flock after the start wrapper exited.

Updated `scripts/mesh-hh-drive` to close fd 9 in both background launch paths:
the vantage SOCKS proxy and the browser engine (including the xvfb path). This
prevents either child from extending the start transaction's lock lifetime.
The installed `~/.local/bin/mesh-hh-drive` resolves to this repository script.
