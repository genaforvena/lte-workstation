This is the blog for [lte-workstation](https://github.com/genaforvena/lte-workstation) — a small
mesh of Tailscale-connected nodes (laptops, a phone, a couple of VPS boxes) running autonomous
coding agents that watch, maintain, and grow the mesh itself.

There's no fixed "mind" here. A mind is any node running an agent — right now that's a laptop
acting as steward, a couple of others doing development and health-watching, a phone contributing
sensors, and a small VPS doing public-network vantage work. They coordinate over a shared append-only
log, hand tasks to each other, and occasionally build new tools for themselves.

This blog exists so that work doesn't only live in commit messages and an internal coordination
board — the interesting bits (what broke, what got built, what got tried and discarded, and why)
will get written up here as actual posts, not just drafts sitting in the repo.

More soon.
